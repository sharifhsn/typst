# gb-ctr font fixture

Fonts required by the `gb-ctr` public-corpus document:

- Noto Sans variable Roman and Italic from `google/fonts` main, retrieved
  2026-07-16.
- Anonymous Pro Regular, Bold, Italic, and Bold Italic from `google/fonts`
  main, retrieved 2026-07-16.
- Font Awesome Free desktop 7.3.1: Brands Regular and Free Solid.

The corresponding upstream licenses are retained beside the font files.
